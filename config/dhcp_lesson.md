# What is DHCP ?

DHCP stands for Dynamic Host Configuration Protocol. It is a protocol that permit to allocate dynamically IP addresses. 
Instead of setting manually the IP addresses on each host (which is very long, contraignant and not enduring. Imagine an enteprise that have to manually configure 1000 hosts...), a DHCP server give all the hosts the IP address that they can use to communicate with the world.
